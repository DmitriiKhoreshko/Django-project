**Веб-приложение на Django для музыкального продюсера**

Платформа объединяет аналитику YouTube, ИИ-инструменты для работы с контентом и финансовый учет.

**Функционал:**

Django-архитектура: Надежный бэкенд на Python/Django, безопасная авторизация, разграничение прав для команды и удобное хранение данных через ORM.

YouTube-аналитика: Автоматизированный сбор данных напрямую через официальный YouTube API. Упор делается на средние и медианные просмотры, что позволяет отсеивать случайные вирусные всплески, оценивать реальный охват аудитории и находить эффективные форматы.

Модуль удаления фона: Интегрированная в сервис легкая модель для быстрого удаления заднего фона. Помогает команде прямо через браузер делать вертикальные сниппеты для TikTok/Reels и промо-материалы без тяжелого софта.

Финансовая отчетность: Сведение метрик монетизации и рекламных бюджетов в единую базу данных с наглядными дашбордами для контроля инвестиций в релизы.

**Технологии: Python, Django, YouTube API, легковесные модели компьютерного зрения.**
